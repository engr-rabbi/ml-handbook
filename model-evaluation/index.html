Model Evaluation & Cross-Validation

Choosing the right metric depends entirely on your problem type, and a single train-test split can badly mislead you. This page covers both.

Metrics Cross-Validation

Regression Metrics

python
from sklearn.metrics import mean_squared_error, mean_absolute_error, r2_score
import numpy as np

mse = mean_squared_error(y_test, y_pred)
rmse = np.sqrt(mse)
mae = mean_absolute_error(y_test, y_pred)
r2 = r2_score(y_test, y_pred)
MetricWhat it tells you
MAEAverage absolute error, in the same units as the target — easy to interpret
RMSELike MAE, but penalizes large errors more heavily
R²Proportion of variance explained by the model (1.0 = perfect)

Classification Metrics

python
from sklearn.metrics import accuracy_score, precision_score, recall_score, f1_score, roc_auc_score, confusion_matrix

print("Accuracy:", accuracy_score(y_test, y_pred))
print("Precision:", precision_score(y_test, y_pred))
print("Recall:", recall_score(y_test, y_pred))
print("F1:", f1_score(y_test, y_pred))
print("ROC-AUC:", roc_auc_score(y_test, y_proba[:, 1]))
print(confusion_matrix(y_test, y_pred))
Accuracy can lie

With 99% class A and 1% class B, a model that always predicts "A" gets 99% accuracy while being completely useless. Look at precision, recall, F1, or ROC-AUC for imbalanced problems.

Cross-Validation

python
from sklearn.model_selection import cross_val_score, StratifiedKFold

scores = cross_val_score(model, X_train, y_train, cv=5, scoring='accuracy')
print(f"Mean accuracy: {scores.mean():.3f} (+/- {scores.std()*2:.3f})")

# For imbalanced classification, stratify the folds
skf = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
scores = cross_val_score(model, X_train, y_train, cv=skf, scoring='f1')
Why it matters

A single split's result can be skewed by a "lucky" or "unlucky" partition. 5-fold cross-validation averages 5 different splits, giving a far more reliable performance estimate.
