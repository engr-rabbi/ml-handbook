Mathematics for Machine Learning

You don't need a math degree to use ML effectively, but a working intuition for linear algebra, calculus, and optimization makes every algorithm — from linear regression to backpropagation — far less mysterious.

Linear Algebra Calculus Optimization

Linear Algebra

Linear algebra is the language of data in ML: every dataset is a matrix, every feature vector is, well, a vector, and every model's parameters are typically stored as vectors or matrices.

Vectors & Matrices

A vector is an ordered list of numbers (e.g., one row of your dataset). A matrix is a 2D grid of numbers (e.g., your entire feature table, rows × columns).

python
import numpy as np

v = np.array([2, 4, 6])          # a vector
M = np.array([[1, 2], [3, 4]])   # a 2x2 matrix

# Dot product — the core operation behind linear regression and neural network layers
a = np.array([1, 2, 3])
b = np.array([4, 5, 6])
dot = np.dot(a, b)  # 1*4 + 2*5 + 3*6 = 32

# Matrix multiplication — how a Dense/Linear layer transforms its input
X = np.array([[1, 2], [3, 4]])
W = np.array([[0.5, 0.1], [0.2, 0.9]])
output = X @ W

Why This Matters

Regression

Linear Regression

The prediction formula y = Xw + b is literally a matrix-vector multiplication plus a bias vector.

Deep Learning

Neural Networks

Every Dense layer's forward pass is a matrix multiplication followed by a non-linear activation function.

Dimensionality

PCA

Principal Component Analysis relies on eigenvectors and eigenvalues of the covariance matrix.

Eigenvalues & Eigenvectors (a quick intuition)

An eigenvector of a matrix is a direction that the matrix only stretches or shrinks (never rotates); the eigenvalue is the amount of stretching. PCA uses this to find the directions of maximum variance in your data.

python
cov_matrix = np.cov(X.T)
eigenvalues, eigenvectors = np.linalg.eig(cov_matrix)
# eigenvectors with the largest eigenvalues capture the most variance —
# these become your principal components

Calculus & Gradients

Almost every ML model is trained by minimizing a loss function, and that minimization relies on derivatives — specifically, the gradient, which tells the optimizer which direction reduces the loss fastest.

The Core Idea: Gradient Descent

Start with random weights
Initialize the model's parameters randomly.
Compute the loss
Measure how wrong the current predictions are.
Compute the gradient
Find the derivative of the loss with respect to each weight.
Update the weights
w = w - learning_rate * gradient — step in the direction that reduces loss.
Repeat
Continue until the loss stops improving meaningfully.
python
# A minimal gradient descent example: fitting y = w*x (no bias) to data
import numpy as np

x = np.array([1, 2, 3, 4])
y = np.array([2, 4, 6, 8])  # true relationship: y = 2x
w = 0.0
learning_rate = 0.01

for epoch in range(200):
    y_pred = w * x
    error = y_pred - y
    gradient = 2 * np.mean(error * x)   # derivative of MSE loss w.r.t. w
    w = w - learning_rate * gradient

print(f"Learned weight: {w:.3f}")  # converges close to 2.0
The chain rule powers backpropagation

Deep networks stack many layers, and computing the gradient for an early layer requires the chain rule — multiplying derivatives layer by layer, backward from the loss. This is exactly what TensorFlow's GradientTape or PyTorch's autograd computes automatically for you.

Optimization Concepts You'll See Often

TermWhat it means
Learning rateHow big a step the optimizer takes at each update. Too high overshoots; too low is painfully slow.
Convex vs. non-convexConvex loss surfaces (like linear regression's) have one global minimum. Neural networks are non-convex, with many local minima.
Local minimumA point where the loss is lower than all nearby points, but not necessarily the lowest overall.
MomentumAccumulates a moving average of past gradients to smooth out updates and escape shallow local minima.
Adam optimizerCombines momentum with per-parameter adaptive learning rates — the default choice for most deep learning today.
You rarely implement this by hand

In practice, libraries like scikit-learn and TensorFlow handle gradient computation and optimization for you. The value of understanding the math is in debugging — recognizing symptoms like a learning rate that's too high (loss oscillating wildly) or too low (loss barely moving).
