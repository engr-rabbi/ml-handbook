The ML Learning Roadmap

A suggested order for working through this handbook, from zero to production. Each stage links directly to its page — skip ahead if you're already comfortable with a topic, or follow it start to finish as a curriculum.

22 stages Beginner → Production
How to use this roadmap

You don't need to complete every stage before starting a project — many practitioners loop back to earlier stages (like Feature Engineering or Model Evaluation) repeatedly as a project matures. Treat this as a map, not a strict prerequisite chain.

Two suggested tracks

If you only care about tabular/business data, you can skip Computer Vision, NLP, and Reinforcement Learning on a first pass. If you're aiming for a research or GenAI-adjacent role, prioritize Deep Learning, NLP, and Computer Vision earlier, right after Supervised Learning.
