Natural Language Processing (NLP)

Converting text into a numeric form a model can learn from is foundational to NLP and GenAI. This page walks from simple counting methods up through dense embeddings and a look at modern transformer-based approaches.

Vectorization Embeddings

Text Vectorization Roadmap

Bag of Words (BoW)
Simple word-count vectors.
N-grams
Add local word-order context.
TF-IDF
Downweight common words, upweight distinctive ones.
Word2Vec
Dense embeddings that capture semantic similarity.
Transformers (BERT, etc.)
Contextual embeddings — the same word gets a different vector depending on context.

Bag of Words & TF-IDF

python
from sklearn.feature_extraction.text import CountVectorizer, TfidfVectorizer

texts = ["I love reading books.", "I love watching movies.", "Books and movies are both fun."]

# Bag of Words
bow = CountVectorizer()
X_bow = bow.fit_transform(texts)

# TF-IDF — downweights common words, upweights distinctive ones
tfidf = TfidfVectorizer(min_df=1, ngram_range=(1, 2))
X_tfidf = tfidf.fit_transform(texts)
print(tfidf.get_feature_names_out())
TechniqueProsCons
BoWFast, simpleNo context, ignores word order
N-gramCaptures local contextHigh dimensionality
TF-IDFDownweights common wordsStill no semantic understanding

Word2Vec — Dense Embeddings

Converts words into continuous vectors so that semantically similar words end up close together in vector space.

python
from gensim.models import Word2Vec

tokenized = [t.lower().split() for t in texts]
model = Word2Vec(sentences=tokenized, vector_size=50, window=5, min_count=1, sg=1, seed=42)

print(model.wv['books'][:5])
print(model.wv.most_similar('books', topn=3))

Text Classification with Deep Learning

python
from tensorflow.keras.layers import Embedding, LSTM, Dense
from tensorflow.keras.preprocessing.sequence import pad_sequences
from tensorflow import keras

vocab_size, max_len, embedding_dim = 10000, 100, 128

model = keras.Sequential([
    Embedding(vocab_size, embedding_dim, input_length=max_len),
    LSTM(64, dropout=0.2),
    Dense(1, activation='sigmoid')
])
model.compile(optimizer='adam', loss='binary_crossentropy', metrics=['accuracy'])

Modern NLP: Transformers & Contextual Embeddings

Since ~2018, transformer-based models like BERT and its successors have become the standard for serious NLP work — they produce contextual embeddings, meaning the same word gets a different vector depending on its surrounding sentence (unlike Word2Vec, which gives each word a single fixed vector).

python
# pip install transformers torch
from transformers import pipeline

classifier = pipeline("sentiment-analysis")
result = classifier("I really enjoyed this handbook!")
print(result)  # [{'label': 'POSITIVE', 'score': 0.999...}]
When to reach for a transformer

For small datasets or simple keyword-driven classification, TF-IDF with a linear model is often a faster, cheaper, and surprisingly competitive baseline. Reach for a pretrained transformer when you need strong semantic understanding, have limited labeled data (transfer learning helps), or the task requires nuanced language understanding.
