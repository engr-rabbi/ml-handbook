Reinforcement Learning

Reinforcement learning (RL) trains an agent to make sequential decisions by interacting with an environment and learning from reward signals — the approach behind game-playing AI, robotics, and recommendation systems.

Agent & Environment Rewards

Core Concepts

Core

Agent

The learner/decision-maker (e.g., a game-playing bot).

Core

Environment

The world the agent interacts with (e.g., a game board).

Core

State

A snapshot of the environment at a given moment.

Core

Action

A choice the agent can make from a given state.

Core

Reward

Feedback signal — positive or negative — for an action taken.

Core

Policy

The agent's strategy: a mapping from states to actions.

The agent's goal is to learn a policy that maximizes cumulative reward over time — not just the immediate reward, which is what makes RL fundamentally different from supervised learning.

Q-Learning — A Foundational Algorithm

Q-Learning learns a "Q-value" for each (state, action) pair, representing the expected future reward of taking that action from that state. Over many episodes, these values converge toward an optimal policy.

python
import numpy as np

# A minimal Q-learning update rule (conceptual, using a simple grid-world Q-table)
n_states, n_actions = 16, 4
Q = np.zeros((n_states, n_actions))

learning_rate = 0.1
discount_factor = 0.95   # how much future rewards matter vs. immediate ones
epsilon = 0.1             # exploration rate

def choose_action(state):
    if np.random.rand() < epsilon:
        return np.random.randint(n_actions)   # explore
    return np.argmax(Q[state])                 # exploit

def update_q(state, action, reward, next_state):
    best_next = np.max(Q[next_state])
    Q[state, action] += learning_rate * (reward + discount_factor * best_next - Q[state, action])
Exploration vs. exploitation

The epsilon parameter controls a fundamental trade-off: exploring new actions to discover potentially better strategies, versus exploiting the best-known action so far. This balance is central to nearly every RL algorithm.

Deep Reinforcement Learning

Real-world state spaces are usually far too large for a table of Q-values. Deep Q-Networks (DQN) replace the table with a neural network that approximates Q-values instead.

python
# pip install stable-baselines3 gymnasium
import gymnasium as gym
from stable_baselines3 import PPO

env = gym.make("CartPole-v1")
model = PPO("MlpPolicy", env, verbose=0)
model.learn(total_timesteps=20000)

obs, _ = env.reset()
action, _ = model.predict(obs)

Algorithm Families

FamilyIdeaExample
Value-basedLearn the value of each action, then act greedilyQ-Learning, DQN
Policy-basedDirectly learn a policy (action probabilities)REINFORCE, PPO
Actor-CriticCombines both: an actor (policy) and a critic (value estimate)A3C, SAC
Where RL fits in practice

RL shines for sequential decision problems with a clear reward signal (games, robotics, resource allocation) but is rarely the right tool for standard prediction tasks — supervised learning is usually simpler, cheaper, and more reliable for those.
