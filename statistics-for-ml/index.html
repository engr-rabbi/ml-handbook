Statistics for Machine Learning

Statistics gives you the vocabulary to describe data, quantify uncertainty, and decide whether a pattern is real or just noise — skills you'll lean on constantly during EDA and model evaluation.

Descriptive Stats Probability Hypothesis Testing

Descriptive Statistics

MeasureWhat it tells youpandas / scipy
MeanThe average value — sensitive to outliers.df['col'].mean()
MedianThe middle value — robust to outliers.df['col'].median()
Standard deviationHow spread out the values are around the mean.df['col'].std()
SkewnessWhether the distribution leans left or right (0 = symmetric).df['col'].skew()
KurtosisHow heavy the distribution's tails are compared to a normal distribution.df['col'].kurtosis()
python
df['price'].describe()
# count, mean, std, min, 25%, 50%, 75%, max — the fastest way to profile a column

Probability Distributions

Continuous

Normal (Gaussian)

The classic bell curve. Many statistical tests assume normally distributed data or residuals.

Continuous

Exponential

Models time between independent events — common in survival analysis and reliability modeling.

Discrete

Binomial

Models the number of successes in a fixed number of independent yes/no trials.

Discrete

Poisson

Models the count of events in a fixed interval — e.g., customer arrivals per hour.

python
from scipy import stats

# Check if a column looks approximately normal
stat, p_value = stats.shapiro(df['price'].dropna())
print("Looks normal" if p_value > 0.05 else "Not normally distributed")

# Compute a Z-score for outlier detection
z_scores = stats.zscore(df['price'].dropna())

Hypothesis Testing

Hypothesis tests help answer: "Is this difference/relationship real, or could it plausibly be random chance?"

TestUse casescipy function
t-testCompare the means of two groups (e.g., A/B test results)stats.ttest_ind(a, b)
Chi-square testTest independence between two categorical variablesstats.chi2_contingency(table)
ANOVACompare means across three or more groupsstats.f_oneway(a, b, c)
Kolmogorov–SmirnovCompare two distributions (also used for drift detection)stats.ks_2samp(a, b)
python
from scipy import stats

group_a = df[df['variant'] == 'A']['conversion_rate']
group_b = df[df['variant'] == 'B']['conversion_rate']

t_stat, p_value = stats.ttest_ind(group_a, group_b)
if p_value < 0.05:
    print("Statistically significant difference between A and B")
else:
    print("No significant difference detected")
p-values are commonly misread

A p-value under 0.05 doesn't mean "there's a 95% chance the effect is real" — it means "if there were truly no effect, you'd see data this extreme only 5% of the time." Small p-values can also arise from large sample sizes even when the actual effect size is tiny and practically meaningless.

Correlation vs. Causation

Correlation measures how two variables move together — it says nothing about whether one causes the other. Ice cream sales and drowning incidents are correlated (both rise in summer), but neither causes the other; a hidden confounder — hot weather — drives both.

python
# Pearson correlation (linear relationships)
df[['feature1', 'feature2']].corr(method='pearson')

# Spearman correlation (monotonic, non-linear relationships)
df[['feature1', 'feature2']].corr(method='spearman')
Why this matters for ML

A model can find and exploit correlations perfectly well without understanding causation — which is fine for pure prediction, but dangerous if you plan to use the model's insights to guide interventions (e.g., "increasing X will improve Y"). For causal questions, you generally need randomized experiments or dedicated causal inference methods.

The Central Limit Theorem

The CLT states that the distribution of a sample mean approaches a normal distribution as sample size grows — regardless of the underlying population's distribution. This is why so many statistical methods (confidence intervals, t-tests) work reasonably well even when the raw data isn't perfectly normal, as long as your sample is large enough.
