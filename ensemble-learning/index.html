Classical ML

Ensemble Learning

Ensembles combine many models to produce a stronger prediction than any single model alone — the backbone of most winning Kaggle solutions and production tabular-data systems.

Bagging Boosting Stacking

Bagging — Bootstrap Aggregating

Trains many models independently on random bootstrap samples of the data, then averages (regression) or votes (classification) across them. This reduces variance and overfitting compared to a single model.

python
from sklearn.ensemble import RandomForestRegressor, RandomForestClassifier

model = RandomForestRegressor(
    n_estimators=200,       # number of trees
    max_depth=15,           # limits overfitting per tree
    min_samples_split=5,
    n_jobs=-1,               # use all CPU cores
    random_state=42
)
model.fit(X_train, y_train)

# Feature importance comes "for free"
importances = pd.Series(model.feature_importances_, index=X_train.columns).sort_values(ascending=False)

Boosting — Sequential Error Correction

Trains models sequentially, where each new model focuses on correcting the mistakes of the ones before it. Generally more accurate than bagging, but more prone to overfitting if not tuned carefully.

python
from xgboost import XGBRegressor
from lightgbm import LGBMRegressor

xgb_model = XGBRegressor(
    n_estimators=300,
    learning_rate=0.05,
    max_depth=6,
    subsample=0.8,
    colsample_bytree=0.8,
    eval_metric='rmse'
)
xgb_model.fit(
    X_train, y_train,
    eval_set=[(X_val, y_val)],
    early_stopping_rounds=20,
    verbose=False
)

lgbm_model = LGBMRegressor(n_estimators=300, learning_rate=0.05, num_leaves=31)
lgbm_model.fit(X_train, y_train)

XGBoostRegularization, robustness, wide adoptionYou want a well-tested, competition-proven default
LightGBMSpeed on large datasets, leaf-wise growthYou have a large dataset and need faster training
CatBoostNative categorical feature handlingYour data has many categorical columns

Stacking

Trains a "meta-model" to combine the predictions of several diverse base models, often squeezing out a final performance boost over any single model.

python
from sklearn.ensemble import StackingRegressor
from sklearn.linear_model import Ridge
from sklearn.ensemble import RandomForestRegressor
from xgboost import XGBRegressor

base_models = [
    ('rf', RandomForestRegressor(n_estimators=200, random_state=42)),
    ('xgb', XGBRegressor(n_estimators=200, random_state=42)),
]

stacked_model = StackingRegressor(
    estimators=base_models,
    final_estimator=Ridge()   # the meta-model that learns how to weight base predictions
)
stacked_model.fit(X_train, y_train)

Bagging vs. Boosting vs. Stacking

ApproachHow it worksReducesExample
BaggingParallel models on bootstrap samples, then average/voteVarianceRandom Forest
BoostingSequential models correcting prior errorsBias (and variance, with regularization)XGBoost, LightGBM
StackingA meta-model learns to combine diverse base modelsBoth, via model diversityRidge on top of RF + XGBoost
A practical starting point

For most tabular problems, start with a well-tuned Random Forest or LightGBM/XGBoost baseline before reaching for stacking — the marginal gain from stacking is often small compared to the complexity and maintenance cost it adds.
