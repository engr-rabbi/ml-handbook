Deep Learning & AI

Computer Vision

Convolutional Neural Networks (CNNs) are the workhorse of image-based tasks — from classification to detection. This page covers building a CNN from scratch, augmenting your data, and fine-tuning a pretrained model.

CNNs Transfer Learning

Building a CNN

python
from tensorflow import keras

(X_train, y_train), (X_test, y_test) = keras.datasets.cifar10.load_data()
X_train, X_test = X_train / 255.0, X_test / 255.0

model = keras.Sequential([
    keras.layers.Conv2D(32, (3, 3), activation='relu', input_shape=(32, 32, 3)),
    keras.layers.MaxPooling2D(2, 2),
    keras.layers.Conv2D(64, (3, 3), activation='relu'),
    keras.layers.MaxPooling2D(2, 2),
    keras.layers.Conv2D(64, (3, 3), activation='relu'),
    keras.layers.Flatten(),
    keras.layers.Dense(64, activation='relu'),
    keras.layers.Dense(10, activation='softmax')
])

model.compile(optimizer='adam', loss='sparse_categorical_crossentropy', metrics=['accuracy'])
model.fit(X_train, y_train, epochs=10, validation_split=0.1)
Why convolutions?

A Conv2D layer slides small filters across the image, learning to detect local patterns (edges, textures) that combine into higher-level features in deeper layers — while using far fewer parameters than a fully-connected layer would for the same input size.

Data Augmentation

Artificially expanding your training set with realistic transformations reduces overfitting and improves generalization.

python
data_augmentation = keras.Sequential([
    keras.layers.RandomFlip('horizontal'),
    keras.layers.RandomRotation(0.1),
    keras.layers.RandomZoom(0.1),
])

Transfer Learning

Loading a model pretrained on a huge dataset (like ImageNet) and fine-tuning it on your own data is the most efficient path to strong performance with limited data and compute.

python
base_model = keras.applications.MobileNetV2(
    input_shape=(224, 224, 3), include_top=False, weights='imagenet'
)
base_model.trainable = False  # freeze the pretrained weights

inputs = keras.Input(shape=(224, 224, 3))
x = keras.applications.mobilenet_v2.preprocess_input(inputs)
x = base_model(x, training=False)
x = keras.layers.GlobalAveragePooling2D()(x)
x = keras.layers.Dropout(0.2)(x)
outputs = keras.layers.Dense(10, activation='softmax')(x)  # your own number of classes
model = keras.Model(inputs, outputs)

model.compile(optimizer='adam', loss='sparse_categorical_crossentropy', metrics=['accuracy'])

Fine-Tuning (Unfreezing Top Layers)

python
base_model.trainable = True
for layer in base_model.layers[:100]:
    layer.trainable = False

# Use a much smaller learning rate to avoid destroying the pretrained weights
model.compile(optimizer=keras.optimizers.Adam(1e-5), loss='sparse_categorical_crossentropy', metrics=['accuracy'])

Beyond Classification

Detection

Object Detection

Locates and classifies multiple objects in an image (bounding boxes). Common architectures: YOLO, Faster R-CNN.

Segmentation

Semantic Segmentation

Classifies every pixel in an image. Common architectures: U-Net, Mask R-CNN.

Where to go next

For detection/segmentation tasks, pretrained model hubs (Ultralytics YOLO, torchvision, TensorFlow Hub) let you fine-tune a strong baseline in a fraction of the time it'd take to build one from scratch.
