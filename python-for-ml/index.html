Python for Machine Learning

Every ML project starts with an isolated environment and a solid grasp of file handling and library imports. This page covers the Conda workflow and the Python fundamentals you'll use in every subsequent chapter.

Environment Setup Core Syntax

Environment Setup with Conda

Before starting any ML project, creating an isolated Python environment is essential so that library versions from different projects never conflict with one another.

Creating and Activating an Environment

bash
conda create --name myenv python=3.10
conda activate myenv

# Create at a specific project path instead
conda create -p ./myenv python=3.10
conda activate ./myenv
A note on location

Environments created with -n are always stored in Conda's root folder — even if you're working on a different drive or folder. To keep the environment inside the project folder itself, use the -p flag.

Complete Conda Command Cheatsheet

TaskCommand
List environmentsconda env list
Deactivateconda deactivate
Delete an environmentconda env remove -n env_name
Install a packageconda install package_name / pip install package_name
Clone an environmentconda create -n new_env --clone old_env
Export to YAMLconda env export > environment.yaml
Recreate from YAMLconda env create -f environment.yaml
Best practice

Create a separate environment for every project, and export an environment.yaml right at the start, committing it to version control. This lets anyone else — or future you — recreate the exact same environment with a single command.

File Handling Basics

ModeDescription
"r"Read mode — the default; raises an error if the file doesn't exist.
"w"Write mode — overwrites any existing file.
"a"Append mode — adds to the end without erasing existing content.
"x"Exclusive creation — errors if the file already exists.
python
def write_file(filename, content):
    with open(filename, "w") as f:
        f.write(content)

def read_file(filename):
    with open(filename, "r") as f:
        return f.read()

def check_file_exists(filename):
    try:
        with open(filename, "r"):
            return True
    except FileNotFoundError:
        return False
Warning

Always use with open(...) as f: — it guarantees the file is closed automatically, even if an exception occurs.
